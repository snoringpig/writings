Touch a vibrating string lightly at its exact middle, without pressing it down, and the note jumps up an octave. Touch it a third of the way along and it jumps to three times the frequency. How can a feather-light finger, which does not even shorten the string, change the note so much?

Listen first: pluck the string, then pick a point to touch and pluck again. String players call these touched notes harmonics.

Touch lightly at

Left end: the nut, near the tuning pegs; right end: the bridge. The motion is slowed for the eye. Stems: how far each mode still swings a quarter of a second after the pluck. The fading rates are an illustrative choice, not measured.

In one sentence. A light touch at the middle of a string moves none of its frequencies: it damps every mode that moves under the finger, and the modes left ringing, the even ones, which stand still there, are the partials of a note an octave up.

Skip to what we hear if you only want the answer.

The operator, in one line

Let the string run along x from the nut, at x = 0, to the bridge, at x = L, with tension T and mass \mu per unit length, and write u(x, t) for its height above the straight line. Newton’s law on a short piece of string gives the wave equation, u_{tt} = c^2u_{xx} with c^2 = T/\mu (post 2 derives it). Subscripts are partial derivatives: u_{tt} is the acceleration of a point and u_{xx} the string’s curvature there, how sharply it bends. Read as a rule that takes the string’s shape and returns minus its acceleration, the equation defines the string’s operator A: u_{tt} = -Au.

The string’s operator. u_{tt} = -A\,u, \qquad A = -c^2\,\frac{d^2}{dx^2}, \qquad c^2 = \frac{T}{\mu}, acting on shapes X on [0, L] with X(0) = X(L) = 0. In words: A takes a shape and returns minus c^2 times its curvature, and only shapes held still at both ends are allowed.

The tied ends, a boundary condition, are part of the operator: they decide which shapes are allowed, and so which frequencies the string has. The model assumes small slopes, a perfectly flexible string, no air and no friction.

Its spectrum

A mode is a shape X that the operator only rescales: AX = \lambda X. The shape X is an eigenfunction, and the number \lambda its eigenvalue. Released in that shape, the string keeps it and swings at the angular frequency \omega = \sqrt\lambda, that is, at f = \sqrt\lambda/2\pi in hertz. The list of all eigenvalues is the spectrum. Solving -c^2X'' = \lambda X with X(0) = X(L) = 0 (fold below) gives the string’s spectrum.

PreciselyThe computation, step by step uses derivatives

1. Which shapes does the operator only rescale? AX = \lambda X says -c^2X'' = \lambda X. Write \lambda = c^2k^2 with k > 0; then X'' = -k^2X, a shape whose curvature is minus k^2 times itself. Its solutions are the waves X = a\cos kx + b\sin kx. (Zero and negative \lambda give no shape that stays still at both ends; see the fold below.)

2. Hold the nut still. X(0) = 0 forces a = 0, so X = b\sin kx.

3. Hold the bridge still. X(L) = 0 then needs \sin kL = 0, so kL is a whole multiple of \pi: k = n\pi/L for n = 1, 2, 3, \dots The shape \sin(n\pi x/L) has n arches.

4. Turn the eigenvalues into frequencies. The eigenvalues are \lambda_n = c^2k_n^2 = (n\pi c/L)^2, so f_n = \frac{\sqrt{\lambda_n}}{2\pi} = \frac{n\,c}{2L} = \frac{n}{2L}\sqrt{\frac{T}{\mu}} = n\,f_1 .

The string’s spectrum. Eigenfunctions: \sin(n\pi x/L), the shapes with n = 1, 2, 3, \dots arches. Eigenvalues: \lambda_n = (n\pi c/L)^2. Frequencies: f_n = n f_1, with f_1 = \frac{1}{2L}\sqrt{\frac{T}{\mu}}, exactly 1, 2, 3, … times the lowest. The lowest rises with the tension and falls with the length and the mass per length.

In plain words: a shape with n arches is n times shorter than the one-arch shape; a shorter shape bends more sharply, and the string pulls back in proportion to how sharply it bends, so it is pulled back n² times harder and swings n times faster. Every shape the string can take is a sum of these arch shapes, so every free motion of the string is a sum of its modes; post 3 shows why, and when such a sum is guaranteed.

ProofNo other eigenvalues uses integration by parts

Write the eigenvalue as \lambda = c^2 k^2 for some number k^2, so that -X'' = k^2 X. Multiply by X and integrate from 0 to L. Integrating by parts, the boundary term -X X' vanishes at both ends because X = 0 there: k^2\int_0^L X^2\,dx = \int_0^L (X')^2\,dx . So a zero or negative \lambda would need \int (X')^2\,dx \le 0, which only the constant shapes satisfy, and the only constant that vanishes at the ends is X = 0. Each eigenvalue (n\pi c/L)^2 has multiplicity 1: the boundary condition at the nut removed the cosine.

Plucked: a ringing string

A plucked string rings: left to itself, it moves as the sum of its modes, each swinging at its own frequency and fading at its own rate, u(x, t) = \sum_{n} a_n\,e^{-t/\tau_n}\sin\frac{n\pi x}{L}\,\cos(2\pi f_n t + \phi_n). What reaches your ear is the string’s push on the bridge, passed on by the wooden body, which keeps every f_n and \tau_n, changes the amounts and adds its own ringing (post 3).

Frequencies: on the lines. They are the spectrum, f_n = n f_1, so apart from the slow fading the sum repeats every 1/f_1 seconds, and is heard at that rate (post 1). The demo uses f_1 = 196 Hz.

Amounts: where you pluck sets the brightness. A pluck starts each shape according to how much of it is in the plucked triangle, and for the same height a shape with more arches has steeper ends, so it pushes the bridge harder. Pluck near the bridge, and the first several shapes push the bridge about equally hard (fold below): the sound is bright. Pluck at the middle, and every shape with an even number of arches is missing, since those stand still where you pulled, and the rest push the bridge less and less, the more arches they have: a mellow, hollow sound. Move the pluck slider in the demo and watch the stems.

Step-by-step derivationHow much of each shape a pluck starts uses integration by parts

Every shape of the string is a sum \sum_n b_n\sin(n\pi x/L) of its modes, its sine series, and b_n says how much of mode n the shape contains. A string pulled aside a distance d at a point x_p from one end, and let go, starts as a triangle. With x_p measured from the nut, where x = 0, its sine coefficients are b_n = \frac{2dL^2}{\pi^2 x_p(L - x_p)}\cdot\frac{\sin(n\pi x_p/L)}{n^2}. Measuring x_p from the bridge instead only flips the sign of every second b_n, since \sin(n\pi(L - x_p)/L) = \pm\sin(n\pi x_p/L), and signs do not change how loud a mode is; from here on x_p is the distance from the bridge. What reaches your ear is driven by the force on the bridge, which is proportional to the string’s slope there and so to n\,b_n for mode n. Near the bridge, x_p small, \sin(n\pi x_p/L) \approx n\pi x_p/L for the first several modes, so n b_n hardly falls off at all: the high modes are strong and the sound is bright. At the middle, \sin(n\pi/2) is zero for every even n, and the rest have n b_n falling like 1/n: a mellower, hollow sound.

Where the formula comes from. Take L = 1 and write q = x_p. The starting shape is u_0(x) = dx/q for 0 \le x \le q and u_0(x) = d(1 - x)/(1 - q) for q \le x \le 1. Its sine coefficients are b_n = 2\int_0^1 u_0(x)\sin(n\pi x)\,dx, because the sines are perpendicular: \int_0^1 \sin(m\pi x)\sin(n\pi x)\,dx = 0 for m \ne n. Integrate by parts twice on each straight piece. Since u_0 vanishes at both ends and u_0'' = 0 on each piece, the only term left comes from the jump in slope at the corner, from d/q just left of it to -d/(1-q) just right of it: b_n = \frac{2}{n^2\pi^2}\big(\tfrac{d}{q} + \tfrac{d}{1-q}\big)\sin(n\pi q) = \frac{2d\sin(n\pi q)}{n^2\pi^2 q(1-q)}. The 1/n^2 comes from that single corner.

Fading, and the player’s damping. Left alone, every mode fades, losing energy to friction in the string, to the air and, through the bridge, to the body; those fading times are measured, not derived here, and the demo’s are illustrative. The player can also cut modes short with a finger, and a finger that damps some modes and spares others answers the puzzle (what we hear).

Pressing down makes a new end. Pressing a finger firmly onto the fingerboard ties the string down there, so it changes the operator itself: only the piece between the finger and the bridge sounds, and by the formula for f_1 a shorter string sounds higher, in inverse proportion to its length. Two-thirds of the length sounds a fifth up, half the length an octave up, and the semitone positions bunch together toward the bridge. Play a whole violin: press and hold a string to bow it, slide sideways to finger it, or switch to plucking.

DetailsWhere the finger goes for each semitone uses powers

An open string is one not pressed down by a finger. With the finger at distance s from the nut, the vibrating length shrinks to L - s, so the pitch rises by the factor L/(L - s). In equal temperament the twelve semitones of an octave are equal ratios of frequency, so each is 2^{1/12}, and k semitones are 2^{k/12}. Solving L/(L - s) = 2^{k/12} gives s_k = (1 - 2^{-k/12})L: the semitone positions bunch together toward the bridge. These are the ticks on the violin’s fingerboard above.

Bowed: a sustained string

A bowed string does not ring and fade. The bow keeps feeding it, and its motion settles into one repeating cycle, Helmholtz motion, at the string’s lowest frequency f_1; a motion that repeats exactly has its partials exactly on the lines (folds below).

DetailsHow the bow locks the note

Playing frequency. A bow grips the string, drags it along until the string’s pull tears it free, lets it slip back, and grips it again, once per cycle. By 1860 Hermann von Helmholtz had watched this through a vibration microscope: the string forms two straight pieces joined by one sharp corner, which races between the bridge and the finger and back, Helmholtz motion. The corner runs at the wave speed c, so the round trip 2L takes 2L/c seconds: the cycle repeats at c/2L = f_1, the string’s lowest frequency.

Waveform. A motion that repeats exactly has its partials exactly on the lines, at n f_1; for Helmholtz motion the push on the bridge in partial n falls off like 1/n (fold below). Even on a real, slightly stiff string, whose own modes run a little sharp of the lines (the piano page), the bowed motion is “nearly exactly periodic”, so bowing reduces the string’s inharmonicity (Wolfe). The locking comes from the bow’s friction, which is not linear; post 3 places it among the self-sustained oscillations, and this page does not derive it. (The demo’s bowed voice adds a gentle vibrato, as players do, which wobbles the lines slightly.)

Slowed about 500 times. The faint lens-shaped outline is the path the corner traces. Stems: the partials of the push on the bridge.

Step-by-step derivationHelmholtz motion as a sum of modes uses the plucked-string formula above

A vibration microscope’s lens rides on a vibrating tuning fork, so that a bright speck on the string traces a pattern revealing its motion. Helmholtz reported what he saw in 1860 and in his 1863 book. The expansion of Helmholtz motion in the string’s eigenfunctions is, for some overall size a, u(x,t) = \sum_{n\ge1} \frac{a}{n^2}\,\sin\frac{n\pi x}{L}\,\sin(2\pi n f_1 t). Where this comes from: at each moment the string is two straight pieces, like a plucked string, with the corner at some point x_c. Helmholtz showed that the corner’s height is proportional to x_c(L - x_c), so it traces two arcs of a parabola, the lens in the demo, and that the corner moves at the wave speed c = 2Lf_1. Put that height in place of d in the pluck formula above: the factor x_c(L - x_c) cancels and b_n \propto \sin(n\pi x_c/L)/n^2. With x_c = 2Lf_1t this is \sin(2\pi nf_1t)/n^2; on the way back the corner runs along the lower arc, and the same formula covers it: for x_c between L and 2L, \sin(n\pi x_c/L) describes a corner at 2L - x_c with negative height. The motion repeats exactly every 1/f_1 seconds, so its partials sit exactly on nf_1. The force on the bridge is proportional to the string’s slope there, and the slope of \sin(n\pi x/L) carries an extra factor n\pi/L, so partial n pushes the bridge with strength proportional to 1/n.

DetailsThe player’s control: bow speed, position and force

The player’s control. The bowing sets loudness and tone. Bowing faster gives a larger swing and a louder note; at the same speed, bowing closer to the bridge also gives a larger swing; bowing with more force, usually closer to the bridge, gives a sharper corner, more high harmonics and a brighter tone; and only a certain range of bow force keeps Helmholtz motion going at all (Wolfe, “Bows and strings”). The note lasts as long as the bow keeps moving.

What we hear

A light touch keeps only the shapes that are still under the finger. The finger is a damper: a soft, lossy contact that takes energy from whatever moves under it. It does not hold the string still there, as a new end would. Where a shape has a still point, a node, the finger has nothing to grab, and that shape rings on; every other shape moves under the finger and loses its energy to it within a moment. The shape \sin(n\pi x/L) is still at the middle exactly when n is even: 2, 4, 6, … arches, at 2, 4, 6, … times the open string’s frequency. Those are whole-number multiples of 2f_1, so the survivors repeat twice as often, and you hear a note an octave up. At a third, the survivors have 3, 6, 9, … arches: three times the frequency, an octave and a fifth up (a factor 2 times a factor 3/2). No frequency moved; the finger changed only which modes keep ringing.

PreciselyWhich modes survive a light touch uses the sine function

Let the finger touch the string at the distance s from the nut, and write X_n(x) = \sin(n\pi x/L) for the shape of mode n. In the model, the finger drains mode n at a rate proportional to X_n(s)^2, how much that mode moves under it, the rule the piano page uses for felt dampers; the demo adds 45 per second times X_n(s)^2 to each mode’s own fading rate. The modes that survive are the ones with a node right under the finger: \sin(n\pi s/L) = 0, which means ns/L is a whole number. At s = L/2 these are the even n, at 2f_1, 4f_1, 6f_1, \dots: a note with fundamental 2f_1. At s = L/3 they are n = 3, 6, 9, \dots, with fundamental 3f_1: an octave (a factor 2) and a fifth (a factor 3/2) up, since 2 \times 3/2 = 3.

The four aspects

The four aspects of the string’s sound, for both ways of playing it:

The violin string’s four aspects.
Aspect Plucked Bowed
Pitch f_1, set by the stopped length and the tension the same f_1, the bowed cycle’s rate
Loudness how far the string is pulled aside bow speed and how near the bridge it plays
Timbre the pluck point; the body’s fixed resonances bow force and position; the body’s fixed resonances
Duration the modes’ fading, or a damping finger as long as the bow moves

The body changes the amounts, never the frequencies. The string rocks the bridge, the bridge shakes the wooden body, and the body moves the air. Each step is linear: shaken at one frequency, it responds at that same frequency, louder or quieter. So the body changes each partial’s height but never its frequency, and its resonances, fixed whatever note is played, are part of the violin’s timbre (Wolfe gives its main air resonance near 300 Hz). What we found

Tied at both ends, the string’s operator A = -c^2\,d^2/dx^2 has its modes at exactly n f_1, so every partial sits on a line. Plucked, the pluck point sets the amounts, and a light touch, a damper, spares only the modes with a node under the finger: at the middle the even ones, an octave up. Bowed, the string runs one repeating cycle at f_1, and the bow sets its loudness and brightness.
